# Pipe-Flow Legacy Reference

This directory preserves the existing working pipe-flow turbulence experiment codebase as legacy reference knowledge.

It is kept for:

- device and protocol knowledge,
- signal-processing logic,
- control heuristics,
- operational sequencing,
- data-output conventions,
- migration reference during development of the new platform.

It is not the architectural base of the new platform.
