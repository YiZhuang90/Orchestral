## Collaboration Docs

This folder is the stable home for reviewer and tester communication artifacts.

Use it for:
- review protocols
- finding templates
- response templates
- future cross-agent communication files

Current files:
- `REVIEW_PROTOCOL.md`: rules for how external reviewers and implementers communicate
- `REVIEW_FINDING_TEMPLATE.md`: required structure for individual findings
- `REVIEW_RESPONSE_TEMPLATE.md`: required structure for implementer responses and retest status

Recommended artifact pattern:
- ad hoc review result: `docs/collaboration/reviews/YYYY-MM-DD-<topic>-review.md`
- implementer response: `docs/collaboration/reviews/YYYY-MM-DD-<topic>-response.md`

This folder is intentionally operational. Architecture and product docs should reference it, not duplicate it.
