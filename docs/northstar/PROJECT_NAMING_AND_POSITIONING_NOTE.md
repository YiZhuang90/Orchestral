# Project Naming And Positioning Note

## 1. Current Chosen Name

**Orchestral**

## 2. Official Subtitle

**Design, Run, and Evolve Experiments with AI**

Full current product-style name:

**Orchestral — Design, Run, and Evolve Experiments with AI**

## 3. Short Positioning

Orchestral is an AI-native experimental operating system designed to help scientists design, integrate, run, document, and evolve custom experiments more easily than traditional tools.

## 4. One-Line Pitch

**An AI-native, layered alternative to LabVIEW for modern custom experiments.**

## 5. Expanded Product Pitch

Orchestral helps researchers design experiments at the system level first, then use AI to turn device manuals, protocol details, and experiment intent into a runnable, documented, and reproducible experimental system.

## 6. Naming Rationale

The name **Orchestral** matches the intended architecture and product experience:

- many devices behave like instruments,
- one experiment behaves like a score,
- the runtime behaves like a conductor,
- the system is meant to coordinate complexity deliberately rather than let it grow organically.

The name also supports the platform vision well:

- it suggests coordination rather than isolated control,
- it feels system-level rather than device-level,
- it is broad enough to grow beyond one experiment,
- it is more product-like than a purely technical codename.

## 7. Brand Meaning

The intended meaning of the brand is:

- structured coordination,
- layered system design,
- controlled complexity,
- scientific seriousness,
- AI-assisted evolution of experiments over time.

## 8. Product Promise

The practical promise behind Orchestral is:

1. define the experiment at a high level,
2. provide device references and desired outputs,
3. let AI help build the device integration and control structure,
4. validate before execution,
5. run with monitoring, stop logic, documentation, and structured data output.

## 9. Strategic Role Of The Name

The name should support the long-term ambition of becoming an AI-native replacement for legacy experimental control workflows, while still being credible for the first wedge:

- custom research experiments,
- mixed hardware setups,
- single-computer orchestration,
- experiments that change often,
- scientists who need less software burden and better design structure.

## 10. Internal Note

The repository and folder names may still reflect the historical project name for some time. That does not change the current product identity direction:

**Orchestral — Design, Run, and Evolve Experiments with AI**
