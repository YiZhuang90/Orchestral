## Purpose Of The Work

SL-002 is EF-02 from the roadmap — a prerequisite for the first reference experiment package (EF-04). It delivers two things:

1. A normative specification (`EXPERIMENT_DATA_SKELETON.md`) that defines the standard file/folder structure for Orchestral experiment data. This is the contract every future consumer (AI agent, analysis script, human) reads from.
2. An update to `RunArtifactWriter` so the runtime emits run directories that conform to the spec: organized into `events/`, `snapshots/`, `metadata/`, and (conditional) `data/derived/` subdirectories instead of a flat layout.

The slice is deliberately scoped to the *run directory* level. Experiment-level routing (`experiments/<id>/runs/<run>/...`) is defined in the spec but not implemented in the writer — that belongs to the caller and is future scope (EF-04). This minimizes blast radius.

### New files

- **`docs/architecture/EXPERIMENT_DATA_SKELETON.md`** (+245) — the normative spec.
  - Section 1: Purpose
  - Section 2: Two-level data model (experiment level = shared structure via `experiment.yaml`; run level = per-execution record via `manifest.yaml`)
  - Section 3: Experiment project hierarchy (`experiments/<id>/runs/...`, `calibration/`, `reports/`, `decisions/` placeholders)
